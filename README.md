# Render Server GUI

Cinema 4D 渲染看门狗与逐帧/分块调度器（Windows 桌面 GUI）  

---

## 模式

| 模式 | 说明 |
|---|---|
| **Team Render（看门狗）** | 常驻监控 `Cinema 4D Team Render Client.exe`，无响应/端口断开/崩溃报告连续达上限即杀并重启；含过热自动休息。 |
| **Cinema 4D.exe（单帧/分块）** | GUI 进程逐帧/分块渲染，异常自动接续。 |
| **Commandline.exe（单帧/分块）** | 与上一模式同一段代码。 |

## 关键特性 / Key Features

- **单帧/分块 N**  最大分块长度 N≥1（自动夹到任务范围），N=5 时一个进程连渲 5 帧。  
- **进度判定**  产物须"存在·非空·距写入≥帧间冷却"才算落定，据此续渲与跳过已完成帧。  
- **异常去抖**  崩溃报告按时间窗计数：命中+1、达上限才杀、出窗清零。  
- **挂起=无进展超时**  GUI 高负载"无响应"不杀进程；连续无新帧落定超过无进展超时才判挂起。  
- **热崩冷却**  每次杀进程后按结果插入 1/30/60s 的空载冷却，兼顾满载散热。  
- **熔断**  连续多块在起点即失败且无进展 → 停止并告警，防整片被"跳着跳着就当渲完"。  
- **多语言**  简体中文/繁體中文/English，界面与后续日志一并切换。  
- **配置持久化**  所有参数存 `settings.xml`，重启恢复。  

## 使用

1. 在渲染机完成 C4D 授权登录，并手动命令行渲一帧确认出图。  
2. 选模式，填主程序/进程名/异常记录路径；单帧模式再填工程文件与输出模板。  
3. 点"预览输出文件名并校验目录"核对命名规则与工程实际输出一致。  
4. 设帧范围与时间参数后"启动"；重开后确认缺帧再填范围续渲。  

## 注意

- 输出必须为图片序列，勿用视频格式。  
- 未烘焙的动力学/布料/粒子缓存会导致中间帧起渲出错画面，先烘焙。  
- 分块省冷启动但块内连渲无冷却，N 取小值并保留块间冷却。
