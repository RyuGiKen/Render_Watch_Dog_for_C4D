两类模式关键差异 + 分层职责

• 分层：内层只管"这一个进程启动后"的观察（含启动后冷却宽限），返回 成功/尝试失败/停止；帧失败计数、重启、跳过、下一帧归外层。
• 无响应：单帧模式不据此杀（高负载常态），只走⑥清零；挂起统一由单帧超时 600s 收口（⑤/⑦）。Team Render 则把无响应计入共享挂起计数。
• 报错(崩溃报告)：两模式都用"时窗命中即 +1、达上限才杀、出窗清零"的去抖；单帧上限=最大异常次数 5、Team Render 上限=最大挂起 4。
• 闪退/正常退出：先判产物——已落定即成功；有产物未落定则等待不误判；无产物才计异常（保留去抖，重启后内层首轮再等冷却跳过加载，避免连锁误判）。
• Cinema 4D vs Commandline：同一段代码，唯一差别是 Commandline 无窗口 → ⑥无响应支自动跳过。
• 时间值：轮询=检查间隔(30s)；帧间冷却(60s)=启动后首轮的加载宽限(此间不检测)，同时用作产物"落定"所需的距最后写入最小秒数；单帧超时(600s)独立。
